# 小智一键视频工坊：AI 全自动工作流升级方案

## 产品目标

同一套视频工作流支持两类内容：
- 产品宣传：商品/门店素材、参考视频、提示词 -> 宣传脚本、镜头计划、画面、配音、音乐、成片。
- AI 漫剧：故事梗概、角色参考、风格提示词 -> 角色设定、场景、分镜、对白、镜头片段、配音、成片。

用户目标流程：上传素材 + 输入提示词 + 点击开始。系统自动执行任务，允许用户在失败时重试单个步骤，并在完成后预览、导出 MP4。

## 工作流阶段

1. 输入与素材检查
   - 支持图片、参考视频、音频、文字提示词。
   - 校验文件类型、大小、数量；显示素材清单。
   - 参考视频只分析镜头节奏、构图、色调等抽象特征，不复制受版权保护的具体内容。
2. AI 导演策划
   - 识别任务类型（产品宣传/漫剧）。
   - 输出结构化项目计划：主题、目标受众、时长、画幅、镜头列表、旁白/对白、字幕。
   - 漫剧额外维护角色外观描述与场景连续性提示。
3. 镜头素材生成
   - 优先使用用户上传素材。
   - 可选接入图像/视频生成服务适配器；不同服务的 API Key 只能放在受保护的服务端环境变量中，绝不写入浏览器代码或仓库。
   - 没有生成服务时，明确降级为图片动态运镜/素材混剪，不声称生成了 AI 视频片段。
4. 音频制作
   - 支持上传音频与可用的中文语音服务。
   - 浏览器语音合成仅作为预览/降级能力；只有确实生成音频文件后，才将其加入导出轨道。
5. 自动剪辑与导出
   - 将镜头、字幕、配音、音乐组合成时间线。
   - 复用现有浏览器编辑器和 FFmpeg WASM 导出能力。
   - 手机端先以短视频、较低分辨率和少量镜头为默认，避免内存耗尽；桌面端可提供更高质量设置。
6. 质量检查与交付
   - 检查素材缺失、时长、音轨、画幅与导出状态。
   - 支持预览、重试失败步骤、下载 MP4、保存项目 JSON。

## 技术边界与安全

- GitHub Pages 只负责静态前端托管，不是 AI 工作流后端，也不能安全保存第三方 API 密钥。
- 真正的 AI 策划/生成需要模型服务；真正的图生视频需要视频生成模型，不能由 FFmpeg 单独完成。
- 先做无密钥可运行的本地工作流（素材检查、脚本/分镜编辑、自动时间线、图片运镜、字幕和导出），再通过可替换的服务端适配器接入 AI。
- 默认免费优先；每个可能收费的服务都必须标明费用、额度和是否需要用户自行配置密钥，不擅自启用付费接口。
- 任何外部服务失败都要给出真实错误和可重试状态，不展示伪造的“生成成功”。

## 迭代与验收

### 第 1 阶段：项目基础
- 修正仓库 GitHub Pages 子路径。
- 中文品牌与产品说明。
- 保留现有多轨编辑器与导出流程。

### 第 2 阶段：全自动工作流界面
- 产品宣传/AI 漫剧两种任务入口。
- 素材上传、提示词、画幅、时长等设置。
- 结构化任务步骤、进度、失败重试。
- AI 导演计划和镜头清单。

### 第 3 阶段：本地自动成片
- 用户图片自动排镜头。
- 自动添加标题/字幕、基础动态运镜、转场和背景音乐。
- 自动创建编辑器时间线并导出 MP4。

### 第 4 阶段：真实 AI 服务
- 先接入可选的文本策划服务，再接图像/视频生成与中文配音。
- API Key 仅由服务端读取；提供费用提示、额度限制和关闭开关。
- 做角色一致性、产品主体一致性和生成结果检查。

### 第一版验收标准
- Android 手机浏览器能完成素材上传、提示词填写和工作流启动。
- 产品宣传和漫剧都能生成可编辑的镜头计划。
- 在不配置付费 API 的情况下，能用用户素材自动生成基础动态视频并导出。
- 不把尚未接入的 AI 视频生成、配音能力伪装成已完成。
