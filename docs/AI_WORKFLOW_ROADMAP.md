# 小智商家短视频生产线：第一版开发路线图

## 产品版本规划

### V1.0：商家短视频生产线（当前唯一主线）

第一版只解决一件事：让不会剪辑的人，也能用手机把商家的照片、视频和文案制作成一条可交付的宣传短视频。

目标流程：选择行业与宣传风格 → 上传门店素材 → 自动生成宣传脚本和镜头计划 → 自动编排画面、字幕、配音和音乐 → 预览修改 → 导出 MP4 → 保存商家项目。

第一版不要求用户配置付费 AI API。没有接入真实生成服务时，必须如实说明使用的是用户素材、模板编排和动态运镜，不得把它宣传成 AI 文生视频或图生视频。

### V2.0：AI 漫剧生产线（第一版交付后再启动）

AI 漫剧不属于 V1.0 验收范围，不应挤占当前商家短视频开发资源。第二版再规划故事创作、角色一致性、场景生成、分镜、对白配音和漫剧成片。

## V1.0 功能范围

1. 商家信息与素材
   - 支持门店名称、行业、宣传重点、目标时长和画幅设置。
   - 支持图片、视频、音频和文案输入。
   - 校验素材格式、数量和大小，并显示素材清单。
2. 商家宣传策划
   - 按行业模板生成宣传脚本、镜头顺序、字幕草稿和拍摄建议。
   - 用户可以修改脚本、字幕和镜头安排。
   - 参考视频只提取节奏、构图、色调等抽象特征，不复制受版权保护的具体内容。
3. 自动剪辑
   - 优先使用用户上传的真实商家素材。
   - 自动创建时间线，支持照片推拉/平移、基础转场和字幕。
   - 配乐与配音分别进入音轨，允许调整音量。
4. 中文语音与字幕
   - 提供普通话配音实验能力和字幕识别/校对工具。
   - 模型下载、中文发音质量、国内网络和 Android 兼容性未通过实测前，不宣传为稳定可用。
   - 语音合成若失败，应提示重试或上传录音，不得伪报成功。
5. 手机预览与导出
   - 手机竖屏优先，提供稳定优先的导出预设。
   - 导出前检查素材、时长、音轨、画幅和内存风险。
   - 导出后给出真实文件状态与格式，不将 WebM 误报为 MP4。
6. 项目保存与交付
   - 多商家项目本机保存、另存为、打开和删除。
   - 自动保存时间线和已导入素材到当前浏览器的 IndexedDB。
   - 支持 .xzproj 完整项目包导入/导出，包含时间线和原始媒体。
   - 项目包必须校验文件路径、ZIP 目录、本地文件头、CRC32 和素材与片段映射。
7. 手机安装
   - 使用 PWA 提供添加到 Android 手机桌面的入口。
   - 需要 HTTPS 正式部署并通过 Android 浏览器实测后，才能宣称安装能力已验收。

## 技术边界与安全

- GitHub Pages 只负责静态前端托管，不是 AI 工作流后端，也不能安全保存第三方 API 密钥。
- 真正的 AI 文案/策划服务需要模型接口；真正的图生视频或文生视频需要视频生成模型，不能由 FFmpeg 单独完成。
- API Key 只能由受保护的服务端环境变量读取，绝不写入浏览器代码或仓库。
- 默认免费优先；任何可能收费的服务都必须说明费用、额度和用户需要完成的配置，不擅自启用付费接口。
- 每个开源模块都要先核查许可证、维护情况、依赖和移动端兼容性；保留上游版权和许可证声明。只有确实适合时才移植，不为“使用开源”而堆叠依赖。
- 外部服务失败时显示真实错误和重试入口，不展示伪造的“生成成功”。

## V1.0 验收标准

- Android 手机浏览器能完成项目创建、素材上传、行业模板选择、自动编排和预览。
- 至少能完成一条约 30 秒商家宣传视频的时间线制作。
- 普通话配音、字幕、背景音乐均有明确的成功/失败状态；无法自动生成时提供可操作的替代路径。
- 能将项目保存到本机，关闭页面后重新打开仍可恢复；能导出并重新导入包含原始素材的完整项目包。
- 手机端能够完成短视频导出，格式、分辨率和文件大小提示准确。
- PWA 在 Android 手机上通过 HTTPS 安装和基本使用测试。
- 完成正式构建、部署和真机验收后，才宣布 V1.0 交付。

## 当前开发分支实现状态（2026-11-27）

以下是代码已接入的能力，不代表已完成 Android 真机或生产环境验收：

- 商家宣传工作流：支持门店资料、行业选择、宣传风格、画幅、目标时长、素材上传、脚本和字幕草稿。
- 行业镜头模板：餐饮、商品、服装、美容美发、酒店民宿、休闲娱乐、其他门店均有六段式拍摄顺序、字幕草稿和拍摄建议。
- 自动编排：照片推拉/平移运镜、镜头与字幕淡入淡出、配乐和配音音量渐变。
- 中文字幕实验室：Whisper 浏览器端实验接入、逐句校对、时间调整、删除、样式选择、SRT 下载和导入时间线；为手机增加 80MB 素材上限和 500 条字幕保护，导入时将字幕时间限制在当前项目时长内。
- 中文配音实验室：Kokoro 浏览器端实验接入；模型下载、普通话质量、移动设备兼容性和国内网络仍待验证。
- 手机导出：触屏/窄屏设备自动采用保持原画幅的最长边 1280px、24fps、中等画质预设；桌面保留原有设置。导出逐帧定位等待浏览器解码完成，超时会明确报错而不是默默使用旧帧。用户仍可手动调整导出参数。
- 手机素材处理：触屏/窄屏设备跳过大视频后台代理转码，避免导入素材时额外启动一套 FFmpeg WASM 并占用大量内存；桌面端仍可按需生成代理。
- PWA：已接入 manifest、安装入口和静态外壳缓存代码，仍需 HTTPS 部署及 Android 浏览器实测。
- 商家项目库：已加入多项目本机保存、另存为、打开和删除；项目与素材按项目 ID 存放，最近打开项目可在启动时恢复。
- 完整项目包：已加入 .xzproj 导入/导出，包含时间线配置和原始媒体 Blob；使用无压缩 ZIP 和 CRC32 校验。正在补强 ZIP 目录、本地文件头、路径安全、重复记录和素材映射校验。
- 项目包自动测试：构建前运行 Node 往返测试；新增 CRC 损坏、路径穿越、重复路径、本地文件名不一致、目录信息异常和缺失素材测试。
- 本机项目自动保存：使用 IndexedDB 保存最近一次项目时间线及已导入素材；只保存在当前浏览器/设备，清理网站数据、浏览器卸载或存储空间被系统回收时可能丢失。
- JSON 项目文件只保存时间线和编辑参数，不包含媒体文件；跨设备完整转移请使用 .xzproj 项目包。
- 限制：ZIP64 和大于 1 GB 项目包不支持；Android 大文件性能仍待验证。

## 本轮手机导出与音频混音改进

- 自动工作流上传的背景音乐现在会延长到整条商家视频的时间线长度；短音乐在预览和导出时循环播放，结尾仍按既有音量关键帧淡出。配音默认不循环。
- 导出混音时，音频片段的播放范围由独立函数计算，并加入自动化测试，覆盖循环、非循环、裁剪起点和越界场景。
- 混音完成后先写入 WAV，再释放大体积 AudioBuffer，随后才逐帧生成 JPEG，降低手机同时持有音频 PCM 与视频帧的内存峰值。
- MP4 编码不再使用 `-shortest` 截断视频；改为按项目时间线时长输出，避免短音频源导致成片提前结束。
- 以上改动已加入构建前测试；仍需 Android 真机验证音频循环听感、淡入淡出、导出时内存峰值及不同浏览器的音频行为。


## 本轮预览与导出同步修复

- 预览播放现在使用与导出相同的音量关键帧曲线，背景音乐淡入/淡出在预览中也能听到。
- 背景音乐循环按原始媒体时长及裁剪区间计算源时间，预览和导出都尊重素材的入点/出点；不会把时间线上的 12 秒错误地 seek 到只有 8 秒的音频文件末尾，也不会循环播放用户已裁掉的片段。
- 音频预览同步阈值收紧，降低长时间播放时音频与时间线的漂移；非循环配音仍按原始时长停止。
- 新增纯逻辑测试，覆盖短音乐循环、裁剪区间循环、配音不循环、音量关键帧和片段边界。
- 仍需在 Android 真机验证不同浏览器对 HTMLMediaElement 循环和后台音频播放的表现。
