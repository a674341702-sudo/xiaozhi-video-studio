# 分享链接解析与参考视频拆解接入方案

## 当前实现

- 首页可识别抖音与小红书分享链接域名。
- 链接经域名白名单校验后，会传递到「参考视频·爆款仿拍研究室」。
- 研究室展示原始分享链接并提供安全的新窗口跳转。
- 分享链接和用户补充说明会预填到观察笔记，便于整理镜头结构。
- 用户仍可上传自己有权保存和分析的参考视频，在浏览器本机提取最多 5 张关键画面。
- 当前不会自动请求、抓取或下载抖音/小红书页面，也不会伪称已观看链接内容。

## 开源项目调研记录

以下项目仅作为技术研究候选，不代表已集成或已通过生产验证：

1. [yzfly/douyin-mcp-server](https://github.com/yzfly/douyin-mcp-server)
   - Apache-2.0；提供抖音链接解析相关能力。
   - 其仓库当前归档状态与运行依赖需要复核；MCP/Python 服务不能直接放入 GitHub Pages 前端。
2. [xuanxuan123xuan/astrbot_plugin_share_forward](https://github.com/xuanxuan123xuan/astrbot_plugin_share_forward)
   - README 声称支持抖音、小红书和 B 站内容解析。
   - 这是 AstrBot 插件形态；小红书需要 Cookie。当前未确认仓库许可证，因此不复制其代码。
3. [Eilens/video-parser](https://github.com/Eilens/video-parser)
   - Apache-2.0；桌面端 Tauri/Rust 应用方向，需改造成服务端接口，不适合直接作为网页依赖。
4. 视频理解可拆为语音转写、关键帧提取和视觉理解三个独立步骤；现阶段先复用浏览器端关键帧提取，后续再接入可替换的服务端模块。

## 推荐架构

GitHub Pages 只承载前端。后续解析服务必须部署在独立后端（例如用户可管理的 CloudBase 云函数或其他受控服务）：

1. 前端提交分享 URL 和平台标识。
2. 后端校验 URL 协议、域名和重定向目标，限制请求超时、响应体大小和重定向次数，防止 SSRF。
3. 平台适配器只读取平台允许公开访问且服务条款允许处理的元数据；不绕过登录、验证码、签名或访问控制。
4. 视频本身若无法合法取得，则提示用户上传其有权分析的视频文件。
5. 视频理解管线可选：ASR 字幕转写 + FFmpeg 关键帧 + 视觉模型摘要。
6. 统一返回结构：platform、title、author（可选）、description（可选）、cover（可选）、transcript（可选）、keyframes（可选）、limitations。
7. 前端将分析结果转为原创脚本和镜头清单，不复制原视频画面、音乐、文案表达、肖像或水印。

## 接入前必须确认

- 具体开源项目的许可证、依赖、维护状态及商业使用条件。
- 平台规则与服务条款是否允许当前抓取/解析方式；不因代码开源而推定平台授权。
- Cookie、账号凭据和 API Key 只可存放于受保护的服务端环境变量，不得写入网页或 Git 仓库。
- 第三方 API 若收费，先向用户明确价格、额度、数据保留政策和退出方案。
- 对解析失败、内容不可访问、服务超时给出明确提示，并保留上传视频/截图/手动笔记的备用路径。

## 暂不采用的做法

- 不在浏览器中直接抓取平台页面（CORS、反爬、登录态和短链跳转均不稳定）。
- 不把 AstrBot 插件或桌面应用整包复制到现有 Vite 网页。
- 不把第三方解析项目的下载地址用于公共模板分发。
- 不在未验证许可的情况下复制无明确许可证的代码。
