# 小智 AI 影视工厂：最终架构与实施计划

## 1. 产品定义

小智 AI 影视工厂是一个面向手机优先的多工作流视频制作智能体。用户只需提供文字、图片、视频和音频素材，由总控导演组织策划、分镜、生成、配音、剪辑和交付。

统一入口包含三条生产线：

1. **商家宣传片**：门店/产品素材 + 商家故事 -> 宣传策略、脚本、镜头计划、字幕、配音、成片。
2. **故事电影**：故事梗概 -> 剧本、人物设定、场景、分镜、镜头素材、旁白/对白、成片。
3. **AI 漫剧**：分集脚本 + 角色参考 -> 角色档案、场景档案、分镜、对白、动态镜头、配音、成片。

三条生产线共用素材库、任务状态、镜头数据结构、时间线编辑器和 MP4 导出引擎。

  ├─ 文生图/图生图适配器

## 3. 当前仓库基础与边界

现有项目是 Vanilla JavaScript + Vite 的浏览器端视频编辑器，包含图片/视频/文字/音频素材管理、多轨时间线、Canvas 预览和 FFmpeg WASM 导出。

GitHub Pages 只托管静态前端，不提供模型推理后端。浏览器端不能安全保存第三方 API Key。FFmpeg 负责合成导出，不会凭空把文字或静态图片变成生成式 AI 视频。

因此分成两种运行能力：

- **免费本地模式**：用户上传素材；本地规则化策划镜头；自动编排时间线；图片动态缩放/平移；添加字幕与用户上传的音乐/音频；导出 MP4。
- **可选 AI 增强模式**：通过受保护的服务端代理接入文本、图片、视频和语音模型。没有配置服务时明确显示“未连接”，绝不伪造生成成功。

## 4. 标准工作流数据结构

每个项目至少保存：

- project：项目 ID、模式、标题、画幅、目标时长、状态。
- brief：用户故事/商家信息、受众、风格、平台、行动目标。
- assets：文件名、类型、大小、用途、用户确认的授权状态。
- characters：角色 ID、外观描述、参考素材、声音设定。
- locations：场景 ID、环境描述、色调和连续性提示。
- shots：镜头 ID、顺序、景别、画面描述、动作、运镜、时长、旁白、对白、字幕、素材引用、生成状态。
- tasks：任务 ID、步骤、状态、进度、错误、重试次数。
- export：画幅、帧率、分辨率、导出状态和文件信息。

所有生成任务都必须有 queued / running / succeeded / failed / skipped 等明确状态。只有实际拿到生成文件，才能把图片、视频或音频标记为 succeeded。

## 5. 手机端产品原则

- 优先竖屏 9:16，默认短片和少量镜头。
- 分步骤填写，不在手机上展示复杂电脑式控制台。
- 素材上传后显示缩略图、名称、大小和删除操作。
- 长任务显示真实进度；失败可单步重试，不丢失已完成素材。
- 导出默认使用适合手机内存的分辨率和帧率。
- 提供“自动完成”和“进入高级剪辑”两条路径。

## 6. 分阶段开发与验收

### 阶段 A：免费本地工作流底座
- 三种工作流入口：商家、故事电影、漫剧。
- 结构化导演镜头计划。
- 用户素材自动匹配镜头、字幕和动态运镜。
- 复用时间线与 MP4 导出。
- Android 浏览器可操作。

验收：不配置任何 API Key，能用真实上传素材生成并导出基础视频；界面清楚标注这不是文生视频。

### 阶段 B：真正的 AI 策划
- 接入可替换的文本模型服务端适配器。
- 自动写脚本、拆分镜、优化旁白和字幕。
- 结构化 JSON 校验、失败重试和人工修改。

验收：模型实际返回的脚本和镜头计划可编辑、可保存；API Key 不出现在浏览器包和 Git 仓库。

### 阶段 C：图片、角色和场景生成
- 文生图、图生图服务适配器。
- 角色参考图、角色档案和一致性提示。
- 场景与道具档案。
- 生成图片进入素材库和对应镜头。

验收：每个生成图有真实文件、来源和状态；漫剧角色设定可跨镜头复用。

### 阶段 D：视频、语音与自动制片
- 图生视频/文生视频适配器。
- 中文 TTS、角色音色、音效适配器。
- 视频镜头与音频自动回填时间线。
- 成片检查：黑帧、静音、字幕溢出、缺失素材、时长。

验收：从输入故事或商家素材到 MP4 的任务链完整可追踪；未配置的服务不会显示成功。

## 7. 零预算策略与安全

- 开发、静态托管和本地剪辑优先使用免费方案。
- 不承诺高质量文生视频、图片生成或大量 TTS 永久免费。
- 每个外部服务接入前显示供应商、免费额度、超额价格、地区限制和隐私说明。
- 默认不自动产生付费请求；用户明确启用后才调用。
- API Key 只能放服务端密钥环境变量，不能放 Vite 的 VITE_* 前端变量、HTML、JS 或 Git。
- 上传素材仅按用户选择的服务发送；本地模式不上传云端。
