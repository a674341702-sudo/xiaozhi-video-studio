# 中国大陆可用性验收标准

本文件是小智视频的硬性产品约束。面向中国大陆普通商家，不能把“海外网络可访问”当成可用，也不能把未经国内网络实测的能力标记为已完成。

## 目标用户体验

- 中国大陆普通网络直接打开；不要求 VPN、代理或修改 DNS。
- Android 手机浏览器优先，微信内置浏览器作为兼容性测试目标。
- 上传素材、生成脚本、配音/配乐、预览、MP4 导出均不能依赖海外 API。
- 默认免费；任何可能产生费用的云资源、API、流量或模型托管必须先说明并获得用户明确同意。

## 当前已知情况（2026-11-28）

- 当前正式预览入口仍是 GitHub Pages。它可以继续用于开发预览，但尚未完成中国大陆网络稳定性验收，不能视为正式国内生产入口。
- `src/ffmpeg-worker.js` 的 FFmpeg 核心文件从本站 `BASE_URL` 加载，并明确禁用了境外 CDN 备用下载。这是正确方向；部署时必须确保 `ffmpeg-core/ffmpeg-core.js` 和 `ffmpeg-core/ffmpeg-core.wasm` 确实随构建产物一起发布。
- 当前 `src/default-music.js` 使用 Web Audio 正弦振荡器合成简单和弦。它不依赖网络，但音色单薄，不应被包装成高质量背景音乐。
- 当前没有完成真正的中文 TTS 集成；没有上传配音时，不能承诺自动生成 AI 人声。
- MOSS-TTS-Nano 官方 ONNX 使用说明在模型缺失时会从 Hugging Face 自动下载。因此，未经国内模型文件托管和真机验证，不允许直接将该自动下载流程接入生产。
- SEEDSONG 是浏览器端程序化音乐项目，但体量小、维护/测试覆盖有限。仅可作为研究素材，不可未经审查直接成为生产依赖。

## 生产架构要求

### 1. 网站与静态资源

- 国内生产入口优先评估腾讯云 CloudBase 静态网站托管；GitHub Pages 保留为开发预览或源码演示。
- CloudBase 默认域名官方仅建议用于开发测试，存在访问频率限制/风险提示；正式生产访问需要已备案的自定义域名。因此在用户没有可用备案域名、且未明确同意任何费用前，不得把 CloudBase 默认域名宣传成正式生产入口，也不得擅自购买域名或升级套餐。先做国内网络测试，再评估合法、零付费可行的正式入口。
- 所有运行时 JS、CSS、WASM、字体、图标、模型和音频资源优先随站点构建并从同一国内站点提供。
- 禁止生产运行时从 unpkg、jsDelivr、cdnjs、Google Fonts、Hugging Face、海外演示站或其他未经大陆验证的域名拉取关键资源。
- 不在前端代码中写入任何 API Key、Secret 或服务端凭据。

### 2. 中文 AI 配音

- 不允许依赖 Hugging Face 首次启动自动下载模型。
- 候选模型必须先确认许可证、模型文件清单和体积，并找到可在中国大陆稳定下载/托管的来源（例如经核验的国内模型仓库或用户自有的国内对象存储）。
- 模型应按需下载、显示大小和进度、允许暂停/重试；模型未准备好时明确提示用户上传录音/配音作为备用。
- 优先做独立实验页或分支，不直接把大模型塞进首页首屏。
- 必须在目标 Android 手机验证中文普通话质量、合成耗时、内存占用、浏览器兼容性和连续生成稳定性。
- 只有完成以上验证后，才能将功能标为“自动 AI 配音可用”。

### 3. 背景音乐

- 音乐必须有明确商业使用授权；记录来源、许可证和适用范围。
- 优先使用经审查的原创/可商用音乐素材，随站点或国内存储提供；同时保留本地生成方案。
- 程序化音乐需先试听并检查旋律、节奏、动态、循环接缝和手机播放质量。不能把单纯正弦和弦当作成品 BGM。
- 不依赖海外音乐 API 或远程音频 CDN。音频资源加载失败时应给出明确提示，不得静默导出杂音。

### 4. 导出与降级

- FFmpeg WASM、Worker、WASM 文件全部自托管；不得在失败时回退到境外 CDN。
- 导出前检查音频轨道是否真实存在且可解码；无配音时清楚提示“当前没有人声”，不误报 AI 配音已生成。
- 导出后检查 MP4 音轨、时长、音量和文件可播放性；失败应阻止生成不完整文件并给出可理解的错误信息。
- 核心功能在网络中断时尽量可继续使用；确需网络的资源应有重试和可解释的降级方案。

## 发布前国内网络验收清单

- [ ] 中国大陆移动网络（至少一张 SIM）首次打开成功。
- [ ] 中国大陆 Wi-Fi 首次打开成功。
- [ ] Android Chrome / 系统浏览器可打开；微信内置浏览器单独测试。
- [ ] 页面无海外关键域名请求；无海外 API Key。
- [ ] FFmpeg JS、WASM、Worker 均从国内生产站点加载。
- [ ] 5 张常见 JPG/PNG 图片导入、编排、预览和导出成功。
- [ ] MP4 可在 Android 相册/主流播放器正常播放，音轨不出现杂音。
- [ ] 中文配音可生成或明确显示备用操作；不可把空音轨说成 AI 配音。
- [ ] 背景音乐可试听，授权可追溯，导出后正常。
- [ ] 首次访问、刷新、弱网、断网、失败重试均有清晰提示。

## 开发纪律

1. 先在独立分支验证，不直接破坏当前可用版本。
2. 每次接入新模型/库，检查许可证、依赖、外链、文件大小、手机内存和构建产物。
3. GitHub Actions 构建通过只是代码检查，不等于中国大陆网络验收通过。
4. 未经国内真机测试的项目只标记为“候选/实验中”，不宣传为已上线。
