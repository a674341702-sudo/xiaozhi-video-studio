# 小智 AI 工作流工厂：手机优先工作台设计

## 产品决策

采用 C 方案：模板运行 + 可视化工作流编辑器。产品首先是一个 AI 内容生产工作台，而不是通用视频剪辑器。商家短视频与 AI 漫剧是同一工作流引擎上的两类模板。

## 用户模式

### 模板模式
- 用户选择商家宣传、餐饮探店、小说转漫剧、漫剧角色与分镜模板。
- 通过手机表单填写需求、上传素材、设置时长与画幅。
- 点击运行后进入任务详情，按步骤显示状态、输出摘要、错误和重试入口。
- 可从任意步骤打开结果进行人工修改；完成后交给现有视频编辑器预览和导出。

### 工作流编辑模式
- 手机优先使用纵向节点列表作为默认视图，节点间显示有向连接。
- 可切换到可缩放画布；在小屏幕上避免强制拖拽连线，提供“选择上游/下游节点”的替代交互。
- 节点支持添加、删除、复制、配置、启用/禁用、运行单节点。
- 连线必须校验端口类型和有向无环图，禁止循环依赖。
- 支持保存、另存为模板、导入/导出 JSON。

## 核心数据模型

Workflow:
- id, name, description, category, version, nodes[], edges[], inputs[], outputs[], createdAt, updatedAt

Node:
- id, type, title, config, inputs[], outputs[], position, enabled

Edge:
- id, sourceNodeId, sourcePort, targetNodeId, targetPort

Run:
- id, workflowId, status, startedAt, finishedAt, nodeRuns[], inputValues, outputValues

NodeRun:
- nodeId, status (pending/running/succeeded/failed/skipped), startedAt, finishedAt, output, error, attempt

## 第一版节点类型

1. 输入节点：文本、图片、视频、音频、文件清单。
2. 素材检查节点：类型、数量、大小和可用性检查。
3. 文案/故事策划节点：第一版可用规则模板；以后接入模型服务。
4. 分镜节点：生成可编辑的结构化镜头清单。
5. 字幕节点：把脚本或对白转换成时间轴字幕草案。
6. 素材编排节点：将用户素材安排到镜头。
7. 视频合成节点：复用现有 Composition、MediaManager 与 FFmpeg 导出。
8. 输出节点：预览、导出 MP4、保存项目文件。

后续可选节点：图像生成、图生视频、中文 TTS、音乐选择、质量检查。只有真实接入服务后才显示为可运行能力；未配置时明确标记“需要服务/密钥”，不得伪造成功。

## 第一批模板

- 商家 30 秒宣传视频：商家资料 + 素材 -> 卖点/脚本 -> 分镜 -> 素材编排 -> 字幕 -> 合成。
- 餐饮探店视频：门店信息 + 环境/菜品素材 -> 探店脚本 -> 镜头清单 -> 合成。
- 小说转 AI 漫剧：故事梗概 -> 角色与场景设定 -> 分集/分场 -> 分镜与对白 -> 合成草稿。
- 漫剧角色与分镜：角色参考 -> 角色档案 -> 场景 -> 分镜草案。

## 手机端交互要求

- 主要操作区适配 360px 宽度；按钮触控高度至少 44px。
- 文件上传明确显示数量、大小和限制；默认控制镜头数和导出分辨率，避免移动端内存耗尽。
- 运行状态可见，页面刷新后可恢复本地保存的工作流草稿和任务状态（第一版先本地持久化）。
- 节点配置采用底部抽屉/独立配置页，不在画布上堆叠小表单。
- 所有主要操作可通过点击完成，不把拖拽作为唯一方式。

## 技术实施原则

- 保留现有 Vanilla JS + Vite 项目、视频编辑器和 FFmpeg WASM。
- 新增独立 workflow-engine 与 workflow-studio UI 模块，避免把业务逻辑继续塞进 auto-workflow.js。
- 第一阶段用浏览器本地执行器运行确定性节点；执行器接口预留后端任务适配器。
- GitHub Pages 仅托管静态前端；真正模型推理、视频生成和高质量语音需要安全的后端服务。
- 任何第三方 API Key 不得放进前端或 Git 仓库。
- 先完成可用的工作流骨架和本地模板，不宣称图生视频、云端 AI 或自动语音已实现。

## 里程碑

### M1：工作流工作台骨架
- 工作台入口、模板列表、编辑器视图。
- 节点/连线数据模型、节点列表视图、基础画布视图。
- 新建、保存、打开工作流；JSON 导入导出。
- 手机端可操作。

### M2：本地执行引擎
- DAG 拓扑排序、节点状态、逐节点执行、失败重试。
- 输入、素材检查、脚本草案、分镜草案节点。
- 本地保存运行记录。

### M3：视频生产连接
- 将分镜与素材编排连接到现有视频编辑器。
- 生成可编辑时间线、预览并导出 MP4。
- 在 Android 真机上测试素材大小、内存和导出稳定性。

### M4：可选 AI 服务
- 服务端模型适配器、费用提示、额度限制和关闭开关。
- 逐项接入文本模型、TTS、图像/视频生成。
- 每个节点明确展示服务配置与实际执行状态。

## 当前已知基础与边界

- 现有项目已有多轨编辑器、Canvas 预览和 FFmpeg WASM 导出。
- 现有 auto-workflow.js 是本地规则式自动编排弹窗，不是通用节点工作流。
- 现有项目没有模型 SDK 或 AI 推理后端。
- 当前阶段不改动现有主分支与已部署版本；所有新开发在独立分支进行。
