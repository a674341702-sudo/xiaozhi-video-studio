# 开源组件集成清单

本文件记录“小智商家短视频生产线”采用的第三方开源组件、集成方式和上线前检查事项。

## 1. 中文自动字幕：browser-whisper（实验接入）

- 上游仓库：https://github.com/tanpreetjolly/browser-whisper
- 当前上游版本：2.0.0（集成时核对）
- 上游代码许可证：MIT
- 本项目接入方式：通过 esm.sh 动态加载 npm 发布包，不复制或修改上游源文件。
- 主要用途：在浏览器本地识别用户选择的视频/音频，返回带起止时间的文本片段。
- 当前模型：whisper-tiny（约 120 MB）为手机默认；whisper-base（约 206 MB）为可选项。
- 语言：明确传入 zh，针对普通话/中文识别。
- 结果：可下载 SRT，或将字幕片段写入现有编辑器文字轨道。
- 首次使用：需要网络加载 esm.sh 组件、WASM运行时和 Hugging Face 模型文件；模型后续缓存能力取决于浏览器存储策略。
- 隐私：音视频通过浏览器端解码和推理，不发送到小智自有服务器；第三方 CDN 与模型仓库会收到正常资源请求。
- 重要限制：尚未在中国大陆网络、Android 真机和低内存设备上完成验证。该功能应标记为实验功能，不得宣传为稳定可用或完全离线。
- 许可提醒：MIT 许可要求保留上游版权和许可声明。browser-whisper 上游还列出了 Transformers.js（Apache-2.0）、ONNX Runtime Web（MIT）、Mediabunny（MPL-2.0）等依赖及各模型权利信息；模型权重不因代码 MIT 许可证而自动变成 MIT。若未来将依赖打包分发或修改依赖文件，需重新核对并保留完整第三方声明。

## 2. 行业镜头模板（本项目自研数据）

- 文件：`src/merchant-templates.js`
- 内容：餐饮探店、商品宣传、服装穿搭、美容美发、酒店民宿、休闲娱乐、其他门店的六段式镜头建议。
- 每段包含镜头角色、字幕草稿和拍摄提示；自动工作流根据所选行业显示拍摄参考，并把建议字幕带入镜头编排。
- 这些模板为本项目原创文案数据，不复制第三方素材；仍需提醒商家按实际经营内容核对，不可把示例字幕当作事实或承诺。
- 该模块没有新增第三方运行时依赖。

## 3. 项目包 ZIP 格式（本项目自研，无新增依赖）

- 文件：`src/project-bundle.js`
- 格式：标准 ZIP 容器，采用 STORE（不压缩）方式，项目清单为 `xiaozhi-project.json`，原始素材独立存放在 `media/`。
- 导入时检查 ZIP 目录、路径、文件大小和 CRC32 校验值；不支持 ZIP64 或压缩成员，避免在手机上引入额外解压依赖和内存峰值。
- 不新增第三方代码或运行时依赖；导出的 `.xzproj` 本质是 ZIP 文件，可作为完整项目备份。
- 当前单包上限 1 GB；大项目建议在手机上拆分素材后再备份。尚未完成 Android 真机大文件压力测试。

## 4. 上线前必须完成的验证

1. Android Chrome 上首次加载组件成功。
2. 使用真实普通话短音频验证中文识别、标点和时间戳。
3. 检查 120 MB 模型下载、缓存和第二次启动行为。
4. 检查手机内存峰值、长音频表现、页面切后台后是否中断。
5. 检查识别失败、网络失败和模型加载失败时的中文提示。
6. 检查 SRT 时间格式及导入时间线后的字幕位置、字号和时长。
7. 确认第三方 CDN / Hugging Face 在目标用户网络环境下可访问；若不稳定，再评估模型镜像或自托管方案及其成本、带宽和许可证。

## 5. 集成原则

- 优先集成成熟项目，不为堆砌功能而引入不兼容依赖。
- 每个组件先检查许可证、维护情况、依赖链、手机兼容性和中文支持。
- 第三方代码、模型、字体、音效和素材分别核对许可证。
- 不在前端代码或仓库中保存 API Key、口令或其他秘密。
- 新功能先进入开发分支和草稿 PR；未经明确同意不合并 main、不发布生产版本。
