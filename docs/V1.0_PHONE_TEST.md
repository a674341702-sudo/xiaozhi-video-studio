# V1.0 安卓手机首轮测试清单

> 本清单用于第一版部署后进行真实设备验收。CI 构建成功不等于已经通过 Android 真机测试。

## 测试前提

- 使用 Android 手机，优先 Chrome 最新稳定版。
- 通过 HTTPS 打开正式测试地址；GitHub 仓库代码页不是应用入口。
- 首轮使用 3–5 个素材，建议总大小不超过 100–160 MB；视频尽量短。
- 导出先选“手机稳定优先”、720p、24fps；手机保持前台并留出足够存储空间。
- 第一次打开中文配音实验室需要联网下载第三方语音模型，模型下载较大，国内网络可能不稳定；配音功能暂列实验性，不作为首轮 MP4 导出阻断项。

## 核心流程验收

1. 打开首页，检查中文界面、按钮和手机布局是否正常，无横向溢出。
2. 打开商家短视频生产线，填写门店名称、行业、宣传重点和目标时长。
3. 从手机相册分别选择图片和短视频，确认素材清单、预览和数量显示正常。
4. 选择行业模板，生成宣传脚本与镜头安排；检查文案是否贴合商家，不出现明显错字或空白段落。
5. 自动编排时间线，检查图片/视频顺序、字幕、配乐和配音轨道是否可见；试听预览。
6. 修改至少一条字幕，保存项目，刷新页面后重新打开项目，确认时间线与素材仍在。
7. 导出 720p / 24fps MP4，检查进度、文件下载、文件大小和播放结果。
8. 在测试副本中再次导出并点击取消，确认界面显示“正在停止”，最终提示“已取消导出”，之后仍能重新开始导出。
9. 导出完整 .xzproj 项目包，再导入该包，检查商家名称、素材数量和时间线是否恢复。
10. 在项目库中创建第二个商家项目，切换、打开、删除其中一个测试项目，确认不会误删另一个项目。

## 记录问题时请提供

- 手机型号、Android 版本、浏览器名称和版本。
- 出问题的步骤编号。
- 页面提示的完整文字或截图。
- 素材数量、单个视频时长和大致文件大小。
- 若导出失败，说明是否成功生成文件、文件能否播放、是否有声音。

## 当前不应误判为已验收的能力

- 中文 TTS 的发音自然度、模型下载成功率和低内存手机稳定性。
- 中文语音识别字幕的准确率。
- 大量素材或长视频的连续导出稳定性。
- PWA 安装后离线使用能力。
- Android 不同品牌浏览器的兼容性。

以上项目需要真实手机测试后才能标记通过。项目库当前保存在本机浏览器 IndexedDB；请定期导出 .xzproj，不要把它当作云端备份。
